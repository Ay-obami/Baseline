# CP1 Runbook

Recorded: 2026-09-21

This runbook closes the remaining environment proof for BaseLine CP1. It is intentionally separate from the later HackCanton DevNet deployment: first prove the package compiles/tests with the supported Daml SDK, then execute the target-network smoke transaction when organizer credentials are available.

## 1. Install DPM

Current Canton documentation identifies DPM as the primary Canton development CLI and documents this Mac/Linux installer:

```bash
curl https://get.digitalasset.com/install/install.sh | sh
export PATH="$HOME/.dpm/bin:$PATH"
dpm --version
```

Official reference:
https://docs.canton.network/sdks-tools/cli-tools/dpm

## 2. Clone BaseLine

```bash
git clone https://github.com/Ay-obami/Baseline.git
cd Baseline/daml
```

For the current compiler-verification branch:

```bash
git fetch origin ci/cp1-daml-verification
git checkout ci/cp1-daml-verification
```

## 3. Install the project SDK

The current `daml.yaml` pins SDK 3.5.7 as a candidate because that is the version generated by current DPM documentation. This is not yet claimed as the organizer-required DevNet version.

```bash
dpm install
dpm version --active
```

## 4. Compile and test

```bash
dpm test
dpm build
find .daml/dist -maxdepth 1 -type f -print
```

Required result before compiler verification is considered complete:

- `Test.Math:testMath` passes.
- `Test.Smoke:testSmoke` passes.
- A DAR is produced under `.daml/dist/`.

Do not merge PR #1 if either Daml script fails.

## 5. Optional local Canton sandbox

Current DPM docs provide a single-participant local Canton instance:

```bash
dpm sandbox
```

Use this only for local integration experiments. A local sandbox does **not** satisfy CP1's target-network gate.

## 6. HackCanton DevNet gate

CP1 is fully complete only after the organizer-supported environment and credentials are known and one smoke transaction is recorded there.

Record, without secrets:

- exact SDK/API version used;
- environment/network name;
- package ID;
- update/transaction identifier;
- git commit;
- authorized owner visibility result;
- outsider visibility result;
- unauthorized exercise rejection.

Do not substitute local `dpm test` or `dpm sandbox` evidence for this target-network receipt.
